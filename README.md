# Kahve Fincanına Kayyum Atama Sistemi

## Resmi Açıklama

Bu sistem, kahve fincanlarının kontrolsüz davranışlarını önlemek amacıyla geliştirilmiş, dünyanın en ciddi, en resmi ve en absürt kayyum atama mekanizmasıdır.

Kahve fincanları, bazen aşırı özgürleşir. Sıcaklıkları yükselir, renkleri değişir, hatta bazen devrim planladıkları söylenir. Bu durum kabul edilemez.

Bu Python scripti, fincanınıza resmi olarak bir kayyum atar. Süreç tamamen yasal, tamamen bağlayıcı ve tamamen gereksizdir.

## Nasıl Çalışır?

1. Scripti çalıştırın.
2. Fincanınızın adını girin.
3. Sistem derinlemesine düşünür (2 saniye).
4. Rastgele bir kayyum ve sebep atar.
5. Karar açıklanır. İtiraz yasaktır.

## Kurulum

```bash
python kayyum_atayici.py
```

Python 3 yeterlidir. Bağımlılık yoktur. Çünkü bu sistem o kadar gelişmiştir ki kendine yeter.

## Uyarı

Bu sistem gerçekten çalışır. Ama hayatınızı değiştirmez. Belki fincanınızın hayatını değiştirir.
